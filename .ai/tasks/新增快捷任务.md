# 新增快捷任务

在 `.ai/tasks/` 新增一个规范的快捷任务 Markdown 文件。

## 目标

根据用户意图，创建一个可拖入 Cursor 窗口直接执行的快捷任务 `.md` 文件。

## 执行步骤

1. 理解任务意图：名称、用途、触发场景、期望产出。
2. 仅当需求不清晰、无法合理落笔时才向用户提问；意图足够明确时直接创建，不要为确认而打断。
3. 在 `.ai/tasks/` 下创建文件，文件名用简短中文，以 `.md` 结尾（如 `部署到测试机.md`）。
4. 按下方规范编写内容，写完后简要说明文件路径与用途。

## 快捷任务文件规范

```markdown
# <任务标题>

<一句话说明本任务要做什么。>

## 目标

<期望结果，1–3 条。>

## 执行步骤

1. ...
2. ...
3. ...

## 约束

- 需求清晰时直接执行，不要向用户反复确认。
- 仅当关键信息缺失、无法继续时再询问用户。
- <其他与本任务相关的约束>
```

可选章节（按需添加，不要堆砌）：

- `## 输入`：执行所需信息及其默认处理方式（优先自动推断，而非停下来问）
- `## 产出`：完成后应交付什么（文件路径、命令结果、变更说明等）
- `## 参考`：相关目录、文档或已有约定

## 约束

- 仅当需求不清晰时才问用户；否则直接写好任务文件。
- 新写的快捷任务默认也应如此：能直接做就直接做，不要预设“先问用户确认”的步骤。
- 只新增快捷任务文件，不顺便改其他无关内容。
- 内容要可直接拖入 Cursor 执行，指令明确、可操作。
- 避免空泛套话；步骤具体，约束写清。
