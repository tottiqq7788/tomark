# 新增快捷任务

在 `.ai/tasks/` 新增一个规范的快捷任务 Markdown 文件。

## 目标

根据用户意图，创建一个可拖入 Cursor 窗口直接执行的快捷任务 `.md` 文件。

## 执行步骤

1. 确认任务意图：名称、用途、触发场景、期望产出。
2. 若任一关键信息不清楚，先向用户提问，不要猜测后直接写文件。
3. 在 `.ai/tasks/` 下创建文件，文件名用简短中文，以 `.md` 结尾（如 `部署到测试机.md`）。
4. 按下方规范编写内容，写完后简要说明文件路径与用途。

## 快捷任务文件规范

```markdown
# <任务标题>

<一句话说明本任务要做什么。>

## 目标

<期望结果，1–3 条。>

## 执行步骤

1. ...
2. ...
3. ...

## 约束

- 信息不清楚时先问用户，不要擅自假设。
- <其他与本任务相关的约束>
```

可选章节（按需添加，不要堆砌）：

- `## 输入`：执行前需要用户提供或确认的信息
- `## 产出`：完成后应交付什么（文件路径、命令结果、变更说明等）
- `## 参考`：相关目录、文档或已有约定

## 约束

- 任务不清楚就问用户，问清再写。
- 只新增快捷任务文件，不顺便改其他无关内容。
- 内容要可直接拖入 Cursor 执行，指令明确、可操作。
- 避免空泛套话；步骤具体，约束写清。
