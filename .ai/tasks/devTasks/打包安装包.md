# 打包安装包

按当前设备类型打出发行安装包，并告知用户产物路径。打包命令与目录以根目录 `agent.md` 为准；`.ai` 任务本身不绑定具体技术栈。

## 目标

1. 确保 `agent.md` 已说明本项目如何打包安装包（命令、产物目录、各平台注意点）。
2. 按当前操作系统打出对应安装包，并回报最终文件路径。

## 平台产物要求（强制）

先识别当前设备 OS（如 `darwin` / `win32` / 其它）：

| 当前设备 | 必须产出 |
|----------|----------|
| **macOS** | **两种** `.dmg`：Intel（x86_64）与 Apple 芯片（arm64 / aarch64），分别可安装，不要只打一个 universal 就当作交差（除非用户明确只要 universal）。 |
| **Windows** | `.exe` 安装包（如 NSIS / 等价安装程序，以本项目打包工具默认为准）。 |
| **其它 OS** | 按 `agent.md` 中该平台约定产出；若未约定，在 `agent.md` 补写可行方案后再打，或说明本机暂不支持并停止。 |

## 执行步骤

1. 读取根目录 `agent.md`，查找打包 / 安装包 / release 相关说明。
2. **若尚未说明**：结合**当前仓库**的技术栈、目录与构建脚本，在 `agent.md` 写入「打包安装包」约定（含各平台命令、目标架构、产物大致路径、依赖与签名注意等），写完再继续。
3. **若已经说明**：不要改写技术栈细节，直接按 `agent.md` 执行。
4. 识别当前 OS，按上方「平台产物要求」与 `agent.md` 执行打包（mac 须覆盖 Intel + Apple 两套 dmg 流程；win 打 exe）。
5. 打包完成后定位产物文件（按 `agent.md` 约定目录查找，或根据构建日志确认），向用户列出**最终安装包的绝对路径**（mac 应列出两个 dmg 路径）。
6. 失败时根据日志与 `agent.md` 排查（工具链、目标架构未安装、依赖等）；不要假装成功。

## 产出

- 必要时已更新的 `agent.md`「打包安装包」说明。
- 符合当前平台要求的安装包文件。
- 回复中的最终打包位置（绝对路径列表）。

## 约束

- 本任务文件不写死具体技术栈或 CLI 命令；一律以当前项目的 `agent.md` 为准。
- `agent.md` 已有打包说明时直接执行，不要另发明流程。
- 需求清晰时直接打包，不要反复确认。
- 除补写/完善 `agent.md` 打包说明外，不顺便改业务功能代码、不往 `plan/` 写文档。
- 遵守 `agent.md` 落盘规则；不要把安装包随意堆到仓库根目录（优先放构建工具默认的 bundle 输出目录，或 `agent.md` 指定位置）。
