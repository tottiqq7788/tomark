## 1. 产品定位

轻量级跨平台 Markdown **桌面**编辑器：左侧编辑源码、右侧查看渲染；**非**所见即所得。目标是「源码清晰 + 预览可靠」，用标题折叠与 Cmd/Ctrl 双向定位减少来回滚动。

## 2. 已实现能力

### 2.1 编辑与预览

- 双栏布局：默认约 1/3 源码 + 2/3 预览；可拖动分隔条，方向键微调比例。
- 三态视图循环：仅源码 / 源码+渲染 / 仅渲染。
- CodeMirror 6 源码编辑：行号、历史、Markdown 高亮、活动行高亮。
- 标题折叠：按 heading 层级折叠；打开时沿首条标题链展开到正文，其余默认折叠；手动展开互斥为单路径（当前节点及其祖先）；编辑中尽量保留折叠状态并映射到新位置。
- 双向定位：Cmd（Windows / Linux 为 Ctrl）点击源码行 → 预览滚到对应块；同修饰键点预览 → 展开并滚到源码。空行落到最近可渲染块；基于 AST 源码行索引，不用标题文本或像素猜位置。
- Markdown 管线：unified / remark（含 GFM）+ rehype-sanitize；预览防抖刷新。

### 2.2 文件与编码

- 单文件工作流：新建、打开、保存、另存为；未命名文档需另存为。
- 已落盘文件停输约 2s 自动保存；工具栏显示待保存 / 已同步 / 编码需手动处理等状态。
- 顶栏可切换显示文件名或完整路径；脏文档有 `*` 标记。
- 原生多编码兼容：自动检测并尽量按原编码往返保存（含 BOM、换行风格）；支持 UTF-8/16、Windows-1252、GBK/GB18030、Big5、Shift_JIS、EUC-KR 等。
- 不可映射字符时暂停自动保存，提供取消 / 另存 UTF-8 / 覆盖为 UTF-8；帮助中可「重新识别」编码。
- 原子写盘；符号链接解析到真实目标后再写。

### 2.3 菜单、快捷键与退出

- 原生「文件」菜单：新建、打开、另存为（对应 Cmd/Ctrl 快捷键）；⌘/Ctrl+S 强制保存。
- macOS 应用菜单含 About / Hide / Quit 等预置项。
- 关窗或退出时：未保存变更弹窗（保存 / 不保存 / 取消）。

### 2.4 状态栏与帮助

- 状态栏：消息、行/字/词统计（大文档防抖）、视图切换、「?」打开使用说明抽屉。
- 帮助内容覆盖折叠、定位、快捷键、默认应用引导、编码重识别等。

### 2.5 系统集成

- 安装包关联 `.md` / `.markdown`；支持从系统打开文件（启动参数、macOS Opened、Win/Linux 单实例二次启动转发）。
- 引导设为 Markdown 默认应用（macOS 系统请求；Windows / Linux 打开系统设置类界面）。
- 预览中 http(s) / mailto / tel 外链用系统打开，不替换应用内 webview。

### 2.6 窗口与外观（平台差异）

- macOS：标题栏 Overlay 与工具栏合并为一行（隐藏系统应用名、红绿灯留白、可拖区域）；栏高约 32px 与红绿灯对齐。
- Windows：保持系统原生标题栏 + 应用工具栏双层结构。
- 蓝灰双栏应用图标（含去白边处理）。

### 2.7 打包与质量

- Tauri 2 发版：`tauri:build`；macOS 可分别产出 Intel / Apple 芯片 DMG；Windows 为 NSIS 类安装包（以构建产物为准）。
- 测试：Vitest + Vue Test Utils 单元/组件测试；WDIO 浏览器与原生 Tauri 冒烟（脏文档、快捷键、关窗等）；Rust 侧部分模块单测。
- 生产构建将 markdown 相关依赖打入单 chunk，避免分包循环依赖导致预览渲染失败。

## 3. 明确未做 / 非目标

- 所见即所得（WYSIWYG）编辑。
- 多标签 / 多文件工作区；同时编辑多个文档。
- 查找替换、拼写检查、minimap、主题与字体偏好 UI。
- Mermaid、数学公式等扩展预览。
- 云同步、多端协作、外部改盘监听与冲突合并。
- 崩溃恢复 / 本地草稿会话备份。
- 应用内嵌浏览器打开外链；非白名单协议链接。
- 代码签名 / 公证作为默认发版能力（未配置时仍可用于本机或未签名分发测试）。
- Linux 发行包细则与 mac/Win 同级的完整打包约定尚未写入项目约定。
- Playwright（约定中曾预留；实际 E2E 为 WDIO）。
- Windows / Linux 的 Overlay 合并标题栏。

## 4. 技术栈与目录映射

| 层级 | 选型 |
|------|------|
| 桌面壳 | Tauri 2 + Rust |
| 前端 | Vue 3 + TypeScript + Vite |
| 编辑器 | CodeMirror 6 |
| Markdown | unified / remark（GFM）+ rehype-sanitize |
| 测试 | Vitest + Vue Test Utils；WDIO E2E |

| 路径 | 职责 |
|------|------|
| `src/` | UI、布局、编辑器、Markdown、预览与联动；Vite/TS 配置 |
| `src-tauri/` | 窗口、文件 IO、编码兼容、系统打开与默认应用等原生能力 |
| `tests/` | 单元、E2E 与 fixtures |
| `deps/` | npm 依赖、构建产物与测试运行入口 |
| `plan/prd/` | 本类产品归档 |
| `plan/misc/` | 调研、纪要等过程产出 |
| `agent.md` / `readme.md` | Agent 约定与公开介绍 |

## 5. 已知限制与可迭代点

- 配置内应用版本号仍为 `0.1.0`，产品语义版本以 git 提交前缀 `vX.Y.Z` 为准。
- `tauri.conf.json` 与 `tauri.macos.conf.json` 窗口字段需双份维护，改尺寸时易漂移。
- Overlay UI 分支当前用运行时平台探测；纯浏览器预览在 Mac 上也可能出现红绿灯占位样式。
- E2E 未覆盖编码冲突全流程、默认应用、macOS Overlay 视觉等路径。
- 多文件同时打开时仅处理第一个 Markdown 路径。
- 未签名安装包在部分系统上可能有 Gatekeeper / SmartScreen 提示。
